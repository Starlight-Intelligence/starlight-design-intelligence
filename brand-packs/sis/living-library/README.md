# SIS Living Library — reference candidate

The editable implementation and its token/icon source live in [examples/sis-living-library](../../../examples/sis-living-library/README.md). This brand-local entry extends the existing SIS pack with a reviewable workbench; it does not change accepted site identity or create a new portfolio design authority.

The study supplies three candidate appearances, 24 original utility icons, material specimens and agent/evidence compositions. It preserves the recovered Starlight star-and-dot geometry. Its source-owned registry payload can be tested in a clean consumer; it is not a published registry or npm release.

The existing material-package proposal, [PR #53](https://github.com/Starlight-Intelligence/starlight-design-intelligence/pull/53), retains the production-candidate glass, gate, Button/Card/Sheet and registry role. Read the [integration matrix](../../../examples/sis-living-library/docs/MATERIALS-INTEGRATION.md) before adoption. Avoid importing both candidate token sheets into one scope.

Product runtime integration stays in the existing Starlight product repository. Figma component/file identifiers stay in the private handoff, as required by the [native-template pipeline](../../../playbooks/figma-template-pipeline.md).
