# Arcanea design foundation · review v1

Status: proposed native projection. Existing production identity and contracts retain authority.

## Decision
Make imagination legible as authored world material. World imagery carries wonder; creator controls carry clarity. A creator should recognize a source, revision, review state and export action without decoding lore.

## Icons
Twelve original 24×24 SVG studies use 1.5-unit strokes, round joins/caps, optional 14% underlay. They are owned construction candidates, not Phosphor assets. Product TASTE specifies Phosphor duotone; the older shared toolchain names Lucide as a portfolio default. Product-specific Phosphor takes precedence for existing UI. Do not mix these study icons into product runtime until the owner selects the migration. Decorative icons are hidden from assistive technology; icon-only controls require an accessible name and 44×44 hit area.

## Structure and states
Spacing uses 4/8/12/16/24/32/48/64/96. UI corners 8–12; image wells may use 16. One dominant action per view. Use restrained separators. Show pending review as text, never color alone. Button states: default, hover, focus and disabled. Field states: empty, filled and error. World flow: find a world → inspect its seed and provenance → edit → review → export. Screen examples use fictional material and show no live product claims.

## Motion and release
Use 150ms feedback and 300ms state transitions only where useful. Reduced motion retains complete content and order. No decorative movement in the authoring area. Native mockups establish composition only; runtime keyboard, long copy, loading/error/recovery, export/restore, performance and screen-reader checks remain required.

## Adoption
Record candidate selection, source hashes, native IDs, export hashes, rights state and exact placements. Submit a source PR, review the resulting browser change and retain rollback. Never promote by editing only a Canva color or Figma variable.
