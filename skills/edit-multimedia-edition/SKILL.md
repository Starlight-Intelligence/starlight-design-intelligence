# Edit a multimedia edition

Open the existing commission, media job and target format. Identify the moment the audience needs to see or hear. Record the source passage, shot or product interaction supporting it. Give each derivative the existing parent content ID and its own version. Keep crops, captions and alternate edits traceable to the same source.

Build a short shot or sequence list with source IDs, time ranges, intended claim, audio/voice rights and fallback. Resolve owned identities before generation or compositing through [character continuity](../review-character-continuity/SKILL.md). Use actual captured behavior for a product demonstration. Disclose staged footage at its point of use.

Edit a review export in the existing production tool. Play the encoded file through its cuts, check caption timing against speech, listen for clipped dialogue and inspect safe areas at destination size. Exercise the muted, paused or static experience as applicable. For a still series, inspect the reading order, smallest type and final crop in each output. Preserve editable originals and register derivatives with the owning system.

Use the existing [media runtime](../../brand-image-system/runtime/README.md) and its supported workflow IDs. Run `node scripts/validate-media-job.mjs <job.json> --asset-root <authorized-root>` for an applicable image job. A video or audio export also needs playback evidence from its owning workflow. Keep unsupported formats and missing rights explicit in the handoff.

Return the private review location, exact output digest, source and rights references, destination and outstanding decision. Cross-check the [Frontier review contract](../../evals/frontier-experience-review.md) before requesting the named publication owner's decision.
