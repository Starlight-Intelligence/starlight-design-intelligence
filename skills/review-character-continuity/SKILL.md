# Review character continuity

Read the [canon retrieval playbook](../../playbooks/character-canon-retrieval.md) and the [owning brand production protocol](../../playbooks/brand-production-foundation.md). Resolve the exact identity, variant, intended use and channel with the authorized VIS adapter. Its [versioned preflight contract](https://github.com/frankxai/visual-intelligence/blob/06be4b2e52ecefa0172c1a15d0a1ada1fd8c4753/skills/visual-canon-retrieval/SKILL.md) identifies the stdio, CLI and operator entry points. Verify that the installed adapter supports the required scope.

Read the original folio and the actual authorized reference bytes. Check the edition, byte digest, current scoped use decision and human owner. Record the adapter result in the existing private job. When any required reference is missing, leave that slot unresolved. Continue with a text label or framing study only where the owning product permits it. A cached thumbnail cannot authorize a model call.

For a character, derive comparison anchors from that exact folio. Inspect the selected crop, pose, silhouette and distinguishing details at placement scale. For moving images inspect first and last frames, cuts, occlusions and the frames after each reveal. For a logo, composite the exact approved file and verify its digest at the compositor input. Preserve variant, clear space and background requirements.

Give a separate reviewer the source and rendered derivative. Record mismatches by frame or placement and retain rejected versions in the private job. Confirm output digest and destination before submitting it for publication review. Authorization for an internal continuity study covers only that study.
