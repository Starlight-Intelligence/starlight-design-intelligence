## 1. Why Most AI Digital Product Funnels Fail

Generic creator funnels fail for four structural reasons:

1. **Averaged visual mush:** Mixing dark SaaS cards, indigo-to-purple Tailwind gradients (`#6366f1` / `#8b5cf6`), warm cream sections, and emoji bullets produces instant "AI template" distrust.
2. **Opaque deliverables:** Asking a technical or creative buyer for USD 47 to USD 297 behind a vague Mockup Box and five benefit bullets hides the actual artifact. Builders want to inspect the file tree, schema, and sample excerpt before paying.
3. **Dead-end lead magnets:** Offering a generic PDF newsletter signup captures low-intent emails without segmenting runtime, skill level, or 14-day build goal, and drops the user onto a dead "Check your inbox" message instead of bridging to the next step.
4. **Rhetorical inflation:** Generic hype slogans, unverified multiplier promises, abstract buzzwords, and contrast clichés lose a perceptive reader in three seconds.

This atlas replaces template guesswork with **seven battle-tested conversion funnel archetypes** extracted from live **Refero MCP** research across real web flows, screens, and design systems.

## 2. The Seven Conversion Funnel Archetypes

### Archetype 1: The 4-Step Diagnostic Fit-Check & Stack Matcher

- **Primary Refero Flows:**
  - **Polaroid Recommendation Quiz** (`Flow 9471`, 11 screens, `https://refero.design/flows/9471`): 4-step card questionnaire (`1/4` to `4/4`), disabled-until-valid confirm gate, brief synthesis state, ranked product match with percentage fit and direct action.
  - **Fit Quiz & Recommendation** (`Flow 7663`, 12 screens, `https://refero.design/flows/7663`): Sequential single-choice questions leading to an email gate that reveals the tailored specification alongside matched products.
  - **Brilliant Personalized Onboarding** (`Flow 4345`, 36 screens, `https://refero.design/flows/4345`): Goal -> current comfort level -> specific topic focus -> tailored path preview before trial commitment.
- **Primary Refero Screen:**
  - **Contra Project Rate & Savings Calculator** (`Screen 4d16a81a-e401-4c6a-b0a4-641da98d5f24`, `https://refero.design/pages/4d16a81a-e401-4c6a-b0a4-641da98d5f24`): Framed dark console displaying two concrete quantified deltas (`TIME SAVED` + `TOOL SPEND SAVED`), breakdown tabs, and inline email capture directly below the computed output.
- **Conversion Mechanics:**
  1. **Step 1 (Current Stack):** Which harness or tool runs daily? (`Claude Code`, `Cursor / Windsurf`, `Codex / OpenCode / Grok`, `Obsidian / Notion only`).
  2. **Step 2 (14-Day Build Target):** What concrete artifact ships in the next 14 days? (`Digital skill pack`, `Content + SEO engine`, `Music / media catalog`, `Client audit / internal automation`).
  3. **Step 3 (Bottleneck):** Where does work stall right now? (`No repeatable offer spec`, `Generic copy and visuals`, `Manual glue across tools`, `Compliance / claims risk`).
  4. **Step 4 (Price / Commitment Band):** Preferred starting lane (`Free starter kit`, `Focused single pack under USD 50`, `Complete blueprint under USD 100`, `Full multi-agent team harness`).
  5. **Output Desk:** Immediate deterministic Week-1 checklist + downloadable free Starter Kit + single matched paid pack (`92% fit` reason shown in plain language) + `DemandSignal` event logged with explicit band intent.
- **Drop-Off Killers:** Never exceed 4 questions before showing value. Keep keyboard `1-4` shortcuts and `Enter` progression active. Allow viewing the diagnostic summary immediately while gating the downloadable `.zip` + Week-1 Markdown checklist behind a single email input.

### Archetype 2: The Two-Pane "Inspect Before You Buy" Pack Workbench

- **Primary Refero Screens & Flows:**
  - **Cycle Template Selection Workbench** (`Screen 618b2107-26a0-40e1-9e7a-9f7689a441f5`, `https://refero.design/pages/618b2107-26a0-40e1-9e7a-9f7689a441f5`): Left-hand structured file/template index with active selection state; right-hand full-height live document preview; sticky primary action in the rail.
  - **Select and Preview Template** (`Flow 1694`, 3 screens, `https://refero.design/flows/1694`): Category filter -> live content inspection -> primary use/acquire CTA.
  - **Teal Template Library** (`Screen fc705008-7230-4c75-be2d-766d1a4c678c`): Filterable left column paired with real specimen output on the right.
- **Primary Visual Containers:**
  - **Warp** (`Style 40a9c295-7a6f-48b3-ae15-2c4d171cf8fb`) + **Convex** (`Style d500b995-352a-4a4f-8016-cb00cdb6eb17`): Dark charcoal workbench (`#121212` / `#141414`), 1px `#2f2f2f` dividers, syntax colors (`#948ae3`, `#fc618d`, `#7bd88f`) strictly locked inside the code/markdown preview pane.
- **Conversion Mechanics:**
  - Every digital pack exposes its real directory tree (`00-README.md`, `SKILL.md`, `schemas/*.json`, `scripts/*.mjs`, `checklists/*.md`), exact file count, total uncompressed kilobytes, and SHA-256 package digest.
  - Clicking any file in the left tree renders an authentic 25-to-40 line excerpt on the right, with a blurred lower fold and an honest footer note (`Showing lines 1-32 of 218 in 01-offer-architecture.md`).
- **Why It Converts:** Replaces marketing adjectives with verifiable craftsmanship. If a reader sees clean schemas, real shell commands, and crisp editorial structure in the preview pane, price resistance drops sharply.

- **Primary Refero Screens:**
  - **Mural Workshop Guide Capture** (`Screen aca74dc4-a712-4a87-97af-03ea1c180446`, `https://refero.design/pages/aca74dc4-a712-4a87-97af-03ea1c180446`): Asymmetric two-column hero: tangible editorial specimen + table of contents on the left; compact capture form + time-to-read metadata on the right.

- **Conversion Mechanics:**
  1. **Left 7 Columns:** Vector technical plate showing exact chapter/folder structure, word count, file formats (`.md`, `.json`, `.canvas`), and a real annotated page excerpt.
  2. **Right 5 Columns:** Literal headline naming the artifact, 3 concrete use cases, single email input, sentence-case primary button (`Send the starter vault`), and zero-spam note (`Direct .zip link + 1 setup note. Unsubscribe in one click.`).
  3. **Post-Submit Bridge (`/delivery/<slug>`):** Instant download button at the top of the screen, 3-command quickstart in the middle, and a quiet, relevant single-pack bridge at the bottom (`Want the automated linter and 14 production templates? Inspect the Claims Guard Pack ->`).

### Archetype 4: The Live In-Browser Telemetry / Config Micro-Audit

- **Primary Refero Flows & Screens:**
  - **Teal Analysis Walkthrough** (`Flow 2718`, 5 screens, `https://refero.design/flows/2718`): Deterministic score readout + specific line-item recommendations + left-side editable input.
  - **Zendesk ROI & Diagnostic Split** (`Screen 29ece5fd-5151-408a-993b-827dbeff0f19`): Input controls on left, live computed diagnostic readout + primary badge on right.
- **Best Portfolio Fit:** `MCP Doctor Diagnostic`, `Claims Guard Copy Linter Preview`, `Prompt Architecture Grader`.
- **Conversion Mechanics:**
  - Visitor pastes a sanitized `mcp_config.json` snippet, landing headline, or Suno prompt into a client-side deterministic evaluator (zero server storage required for raw input).
  - Evaluator outputs an instant pass/warn/fail table (for example: plaintext API key exposure, missing stdio fallback, em-dash overuse, vague CTA verb).
  - Free tier gives the immediate fix; paid tier (`Claims Guard Pack` or `System Architect Starter Kit`) ships the full repo pre-commit hook, CI workflow, and 30-rule pack.

## 4. Universal Craft & Conversion Rules

1. **Sentence-case labels everywhere:** Badges, tabs, navigation items, and buttons use sentence case (`Free starter kit`, `Inspect 6 files`, `Reserve edition 01`), never shouting `ALL CAPS` banners.
2. **One primary action per viewport:** Secondary paths (`Inspect files`, `Read sample chapter`) use quiet ghost or text-link treatments so hierarchy is instantaneous.
3. **Code-exact SVG plates over fake 3D boxes:** Digital products are software, specifications, vaults, and prompt systems. Represent them with razor-sharp vector schematic plates (`viewBox="0 0 640 360"`, `16:9` aspect), real file manifests, and live interactive previews rather than warped Photoshop book boxes.
4. **Motion budget:** Micro-feedback (`90-150ms`), tab/file-tree state switches (`160-220ms cubic-bezier(0.0, 0.0, 0.2, 1)`), and full `prefers-reduced-motion: reduce` instant state swaps.
5. **Structured `DemandSignal` telemetry:** Every pre-checkout door, fit-check completion, and waitlist reservation records `{ productSlug, funnelArchetype, priceBand, runtimeStack, goal14d, sourcePath }` without PII leakage so human promotion decisions follow real buyer pull.
