# Living Agent UI pricing assessment

Observed 13 November2026. VERIFIED facts below come from official product/terms pages. Commercial decisions and all economics are PROPOSED, not activated offers or observed customer demand. Prices remain in source currencies; no exchange-rate comparison is implied.

## Decision

€79 Pro is a defensible launch price for one qualified agent UI kit and Next.js starter. €199 Studio is defensible only after its promised complete templates pass install/use acceptance. Sell a narrow operational advantage: typed agent events, controlled generative UI, exact-action approvals, source evidence, portable runtime boundaries and installable artifacts. Raw component count cannot compete with established catalogs.

Do not sell the seven-product roadmap as current inventory. Keep Studio disabled until Agent Command Center plus Research and Creator templates actually qualify. Preserve recovered Glass Essential/Professional/Command Center SKU ownership; these proposed bundle labels are mappings to that catalog, not permission to create replacement Stripe products.
