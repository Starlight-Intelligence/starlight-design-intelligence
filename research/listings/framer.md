# Framer draft: Glass Core AI startup site

Status: draft, not listable as is. Requirements read 2026-11-21 from "How to publish a template" (https://www.framer.com/help/articles/how-to-publish-a-template/).

## What Framer requires

- Name, byline and description
- Images, categories, styles and features
- A preview URL and a remix URL
- Payment settings for paid templates
- Templates publish immediately; there is no review. Sellers keep 100% of paid sales, and may sell the same template elsewhere.

## Why this kit cannot be listed yet

A remix URL is a Framer project. Glass Core is Next.js source. Listing on Framer means rebuilding the composition natively in Framer: the shader field as a Framer code component, the ledger and lens as components with variants, and the agent endpoints dropped (Framer hosts the site; `/api/mcp` and route handlers do not exist there). That is a separate product decision, not a port.

Because Framer publishes with no review, any future submission must pass the human gate before the button is pressed.
