## Title (Envato style, max length [OPEN])

Glass Core: AI Startup Next.js Template with Agent-Readable Pages

## Short description

Next.js 16 template for AI startups: landing, pricing, sign-up and docs, phone first, with llms.txt, JSON-LD and a read-only MCP endpoint.

## Features list

- Next.js 16 App Router, React 19, TypeScript
- Landing page built around a verified run ledger with a magnifying lens
- WebGL shader field with poster fallback, off-screen pause and reduced-motion still frame
- GSAP motion with a written job per animation and a reduced-motion path
- Pricing with monthly and yearly billing, JSON-LD Product and Offer
- Sign-up page with local validation and a provider hook
- Docs shell with filter, disclosure navigation on phones and an assistant slot
- llms.txt, /.well-known/starlight.json and a read-only MCP endpoint
- Web app manifest with generated PNG icons including maskable
- Playwright tests: Pixel 7, reduced motion, desktop
